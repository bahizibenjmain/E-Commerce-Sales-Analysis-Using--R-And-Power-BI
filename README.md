#  E-Commerce Sales Analysis Dashboard (Power BI + R)

## Project Overview

This project analyzes an e-commerce sales dataset using **R Programming** and **Power BI** to uncover business insights related to sales performance, customer purchasing behavior, payment methods, and revenue trends.

The project combines:
- **Data analysis in R**
- **Interactive dashboard development in Power BI**
- **Business insight generation through visualization**

---

#  Objectives

The main objectives of this project were to:

- Clean and prepare the dataset for analysis
- Analyze revenue and sales trends
- Identify top-performing products
- Explore customer payment methods
- Examine order status distribution
- Build an interactive business dashboard
- Visualize important business insights

#  Dashboard Features

The Power BI dashboard includes:

- KPI Cards
  - Total Revenue
  - Total Orders
  - Total Quantity
  - Average Order Value

- Revenue Trend Analysis
- Top Performing Products
- Order Status Overview
- Payment Method Distribution
- Revenue by Referral Source
- Interactive Filters and Slicers

---

#  Key Insights

- Certain products generated significantly higher revenue than others
- Revenue trends varied across months and years
- Customer payment methods showed different usage patterns
- Referral sources contributed differently to total revenue
- Order status analysis revealed delivery performance trends

---

#  Data Cleaning Process

The dataset was cleaned in R by:
- Removing missing values
- Removing duplicate records
- Creating calculated variables such as `TotalRevenue`
- Formatting date variables for monthly and yearly analysis
